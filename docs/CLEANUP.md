- `codex/research-before-cleanup`：仅本地保留整理前的源码，包括当时已有的未提交源码修改；不得发行。

存档及派生游戏二进制从不因保存开发分支而进入 Git。

## 发布边界

原有 Git 历史审计没有发现已提交的 ROM、提取二进制、图片、存档或压缩包，也未发现凭据，
但含旧实验与个人路径，因此留在本地研究分支。现有研究历史未被重写；
公开开发分支另建干净根提交，公开元数据移除了本机绝对路径。
整理结果与整理前源码均已在本地 Git 分支提交；尚未推送、创建远程仓库或发布 Release。
获准发布时只推送 `codex/development`，不要使用 `git push --all` 或 `git push --mirror`，
也不要发行研究分支、原有研究历史或含这些分支的完整 `.git` 目录。

`local/` 仍是私人数据区。任何分发都必须用白名单，不能压缩整个物理项目文件夹。
许可证按用户选择设为 MIT，第三方和游戏权利不包含在内。
